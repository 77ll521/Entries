制造企业文案助手 · 网页版

本网页版提供基础款能力：用内置的行业模板把产品参数套成六段营销文案，无需联网、无需密钥、打开即用。

快速上手

  1. 在「✨ 生成文案」里粘贴产品参数（带上「产品名称 / 行业品类 / 材质 / 尺寸规格 / 交期 / 认证」效果最佳），点「一键生成六段文案」。
  2. 结果分 6 个标签：1688 硬核工业风、短视频、朋友圈短文案、AI 绘图 Prompt、博客、邮件。
  3. 「🔍 产品资料查询」可导入你自己的 Excel/CSV 产品库，按编号查询、点行查看、编辑、删除。
  4. 「📝 模板管理」可改各行业模板：每个字段有 4 套备选（版本1 稳健 / 版本2 激情 / 版本3 专业 / 自定义）。

关于数据保存

网页版的数据（产品库、模板修改、AI 密钥）保存在当前浏览器本地。清理浏览器缓存 / 换浏览器会丢失，重要数据请用「📤 导出」备份。

两档模式：基础款 / 升级款

  • 基础款（默认，无需联网）：用内置行业模板套用生成，打开即用、无需密钥。
  • 升级款·AI：点右上角「⚙ 设置」填入你自己的大模型 API 密钥（如 DeepSeek），保存后切到「升级款·AI」，即可让模型生成更丰富、更贴合的文案。密钥只存你本机浏览器，不会上传。若浏览器直连接口报跨域/网络错误，属正常网络限制，可在「设置」里改用支持跨域的代理接口地址。
