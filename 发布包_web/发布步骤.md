# 网页版发布上网 · 图文步骤

> 目标：把这个纯静态网页发布到互联网，拿到一个**任何人点开就能访问**的网址（评审直接点链接看）。
> 全程免费，不需要买服务器、不需要写代码。

---

## 一、发布包里有什么

`发布包_web/` 里这 **11 个文件**必须全部一起上传（缺一个页面功能就会缺失）：

```
index.html        ← 主页面（文案助手：基础款 + 升级款AI）
app.js            ← 主页面逻辑
templates.js      ← 模板数据
keywords.js       ← 行业关键词
general.js        ← 通用兜底数据
compliance.js     ← 广告法合规检测（绝对化用语自动替换）
parser.js         ← 智能参数识别（本地规则，零依赖）
library.html      ← 模板库页面（110 个产品 / 330 套现成模板）
library.js        ← 模板库数据（较大，约 459KB，正常）
library_app.js    ← 模板库页面逻辑
styles.css        ← 样式
```

> 说明 1：`compliance.js` 和 `parser.js` 绝不能漏——漏了页面虽然不白屏，但「智能参数识别」和「广告法合规检测」会静默失效。
> 说明 2：发布包**不放 exe**（11MB 太大且会被杀软拦），页面右上角也**不再提供“单机版 / exe 下载”入口**，网页版功能本身完整可用。
> 说明 3：本文件（`发布步骤.md`）只是操作说明，**不需要上传**。
> 说明 4：上一级目录里的 `网站发布包.zip` 就是这 11 个文件的压缩版，可以直接解压后按下面的步骤上传（压缩包里另附本说明）。

## 二、方案 A：Gitee Pages（码云，国内访问稳定，推荐）

### 第 1 步：注册并实名
1. 打开 https://gitee.com → 注册账号
2. 右上角头像 → 账号设置 → 实名认证（**不实名无法开 Pages**，一般几分钟到 1 天通过）

### 第 2 步：新建仓库
1. 右上角「+」→「新建仓库」
2. 仓库名称填：`copy-web`（或任意英文名）
3. 选择「公开」（必须公开，私有仓库 Pages 需付费）
4. 点「创建」

### 第 3 步：上传文件
1. 进入刚建的仓库 → 点「上传文件」按钮（或在仓库首页点「+」→「上传文件」）
2. 把 `发布包_web/` 里的 **11 个文件全部拖进去**（注意：要拖"文件"本身，不要拖外层的文件夹，否则路径会多一层）
3. 下方填提交信息如「init」，点「提交」

### 第 4 步：开启 Pages
1. 仓库页顶 →「服务」→「Gitee Pages」
2. 部署分支选 `master`（或 main），部署目录留空（根目录）
3. 点「启动」
4. 稍等几秒，出现网址，形如：
   `https://你的用户名.gitee.io/copy-web/`

### 第 5 步：访问
- 主页面：`https://你的用户名.gitee.io/copy-web/index.html`
- 模板库：`https://你的用户名.gitee.io/copy-web/library.html`

> ⚠️ Gitee Pages 每次改了文件，要在「服务 → Gitee Pages」里点「更新」才生效。

## 三、方案 B：GitHub Pages（不用实名，但国内偶尔打不开）

### 第 1 步：注册
打开 https://github.com → 注册账号

### 第 2 步：新建仓库
1. 右上角「+」→「New repository」
2. Repository name 填：`copy-web`
3. 选「Public」→「Create repository」

### 第 3 步：上传
1. 仓库页点「Add file」→「Upload files」
2. 把 `发布包_web/` 里的 11 个文件全部拖进去
3. 点「Commit changes」

### 第 4 步：开启 Pages
1. 仓库页 →「Settings」→ 左侧「Pages」
2. 「Source」选 `Deploy from a branch`
3. Branch 选 `main`，目录选 `/ (root)` →「Save」
4. 等 1~2 分钟，刷新页面，顶部出现网址：
   `https://你的用户名.github.io/copy-web/`

### 第 5 步：访问
- 主页面：`https://你的用户名.github.io/copy-web/index.html`
- 模板库：`https://你的用户名.github.io/copy-web/library.html`

> ⚠️ GitHub Pages 国内有时打不开，若担心，优先用 Gitee。

## 四、常见问题

**Q1：页面白屏 / 样式全乱？**
→ 多半是文件没传全或路径多了一层文件夹。确认 11 个文件都在**仓库根目录**（和 index.html 同级）。

**Q2：模板库打不开 / 显示 0 条？**
→ 检查 `library.js` 是否上传成功（它约 459KB，别漏）。它必须和 library.html 同级。

**Q3：升级款 AI 能用吗？**
→ 能。用户在「⚙ 设置」里填自己的密钥即可（密钥只存他自己浏览器，不上公网、不泄露）。

**Q4：能不能被百度/必应搜到？**
→ 发布后可以被访问，但"被搜到"要另外做（提交收录、等爬虫，几天到几周、不保证排名）。**评审通常直接点你给的链接，不需要被搜到。**

**Q5：以后改了内容怎么更新？**
→ 重新上传改动过的那个文件覆盖，Gitee 记得点「更新」重新部署，GitHub 会自动部署。
